Embed live government data

Put a live RBI rate, forex-reserves or Union-Budget card on your own site, blog or newsletter. One line of HTML, one script tag. No account, no key, no tracking. Numbers update at the source — from kya haal junta?

1. Add a placeholder + the script

<div data-khj="repo"></div>
<script src="https://infojunta.vercel.app/embed/widget.js" async></script>

Set data-khj to repo, forex or budget. Add as many as you like — one script tag covers them all.

2. Live preview

data-khj="repo"
data-khj="forex"
data-khj="budget"

Prefer to mount it yourself?

<div id="my-rate"></div>
<script src="https://infojunta.vercel.app/embed/widget.js"></script>
<script>KyaHaalJunta.render("#my-rate", "forex");</script>
Data belongs to its publishers (RBI, Ministry of Finance). kya haal junta? only makes it readable. Widgets are free to use and attribute back to the source.
